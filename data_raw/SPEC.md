# 各國教學內容撰寫規格

用途：給台灣國小中高年級（9–12 歲）上課用的「世界國旗探索」網頁。老師會投影，學生也會自己點。
語言：台灣慣用繁體中文（台灣用語與譯名，例如「紐西蘭」「沙烏地阿拉伯」「哥斯大黎加」「肯亞」「奈及利亞」「義大利」「雪梨」）。

## 輸出
一個 JSON 陣列檔，每個國家一個物件，順序同輸入批次檔。欄位：

```json
{
  "id": "jp",
  "zh": "日本",
  "zhFull": "日本國",
  "capital": "東京",
  "languages": "日語",
  "intro": "日本是位在亞洲東邊、由許多島嶼組成的國家。這裡有很多火山和溫泉，也常常發生地震。日本人很重視禮貌，動漫和電玩也很有名。",
  "features": ["🗻 富士山", "🌸 櫻花", "🍣 壽司", "🚄 新幹線"],
  "flagNick": "日之丸",
  "flagMeaning": [["白色", "純潔、誠實"], ["紅色圓形", "太陽，日本是「太陽升起的地方」"]],
  "flagColors": ["紅", "白"],
  "flagSymbols": ["圓形", "太陽"],
  "people": [
    {"emoji": "✏️", "name": "手塚治虫", "role": "漫畫家", "desc": "被稱為「漫畫之神」，畫了《原子小金剛》。"},
    {"emoji": "⚾", "name": "大谷翔平", "role": "棒球選手", "desc": "又會投球又會打擊的「二刀流」明星。"}
  ],
  "ask": "日本國旗只有兩種顏色，你猜紅色圓形代表什麼？",
  "funFact": "日本有超過 6,800 座島嶼。",
  "check": []
}
```

## 欄位規則
- **zh**：台灣常用的國名簡稱。台灣的 id=tw 寫「台灣」；cn 寫「中國」；ps「巴勒斯坦」；xk「科索沃」；va「梵蒂岡」。
- **zhFull**：正式全名的中文。
- **capital**：首都的中文譯名。有爭議或多首都的就簡單說明，例如「普勒托利亞（行政首都）等 3 個」。
- **languages**：主要語言，最多 3 種，用「、」分隔。
- **intro**：2～3 句，60～90 字，小學生聽得懂，講地理位置的特色加上一兩個生活或文化特色。不要寫戰爭、屠殺、政治爭議、貧窮的負面描寫；不寫會很快過時的數字。
- **features**：3～4 個，每個是「emoji＋空格＋2～8 字」，例如景點、食物、動物、運動、節慶。
- **flagNick**：國旗的通稱，沒有通稱就寫空字串。
- **flagMeaning**：2～4 項 [顏色或圖案, 代表意義]，意義 25 字以內。用官方或最常見的說法；沒有把握的不要寫，寧可少寫。
- **flagColors**：只能從這些選：紅、白、藍、綠、黃、黑、橘、其他。列出國旗上明顯的主要顏色（淺藍、深藍都算「藍」；金色算「黃」；褐色、紫色等寫「其他」）。
- **flagSymbols**：只能從這些選，可以是空陣列：星星、太陽、月亮、十字、動物、植物、武器、文字、徽章、三角形、圓形、橫條紋、直條紋。
- **people**：2～3 位，適合國小學生認識的正面人物：科學家、發明家、藝術家、音樂家、作家、運動員、探險家、環保或人權人物、受普遍尊敬的建國或獨立領袖。
  - 不要放：獨裁者、戰犯、極具爭議的政治人物、仍在任的政治人物、宗教創始人（避免信仰爭議）、有重大醜聞的人。
  - 你必須有把握這個人真的存在、真的是這個國家的人、描述的事蹟正確。沒把握就換人或少放一位；小國實在找不到可以只放 1 位。
  - **emoji**：一個代表他職業或事蹟的 emoji（不要用人臉 emoji 代表本人）。
  - **role**：2～6 字。**desc**：一句話，30 字以內。
- **ask**：一個「老師問」，引導學生觀察國旗或思考這個國家，35 字以內。
- **funFact**：一句有趣、確定正確的冷知識，40 字以內。
- **check**：你覺得老師上課前應該再確認的地方（字串陣列），沒有就空陣列。

## 品質要求
- 正確性第一。數字只寫你非常確定的（例如最高峰高度、世界紀錄）。
- 台灣用語、全形標點（，。「」、），數字與中文之間留半形空格。
- 寫完用 Python 讀回檢查：是合法 JSON、筆數與 id 和輸入一致、每筆欄位齊全、flagColors／flagSymbols 只用允許的值。
